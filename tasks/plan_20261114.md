# UI simplification — 2026-11-14

User request: "The interface needs to be simplified. E.g. choosing A and B
should be done by clicking the minimap (to open the 2D map), not its own
button. Without reducing functionality, simplify!"

## Inventory before
Five ways to make a route: NEW STAGE button (+N), ROUTE BUILDER button (3D
topo picker), 2D MAP button (Leaflet), OSRM ROAD ROUTER (four coordinate
fields + FETCH), and minimap click-twice. Plus RESTART STAGE (+R).

## Plan
- [x] Minimap is clickable and opens the 2D map (the only picker). Remove the
      minimap click-twice routing and its pick state.
- [x] 2D map profile select gains **off-road (A\*)** so the game's own router
      is still reachable (points must lie inside the loaded world).
- [x] 2D map gains one `lat, lon` field: Enter places the next pin (replaces
      the four-field OSRM panel; FETCH = GENERATE ROUTE).
- [x] Remove the 3D route builder (panel, orbit camera, pick markers, canvas
      pointer handlers, topo drape mesh). Keep the topo texture for the minimap.
- [x] Stage panel: stats + NEW STAGE / RESTART only, foot says "click the
      minimap to pick a route". Remove 2D MAP, ROUTE BUILDER, OSRM details.
- [x] 2D map footer: drop CLEAR (a third click already starts over).
- [x] Start screen: car / gearbox / sliding toggles on one row.
- [x] Help line, start copy, README, ARCHITECTURE, CHANGES, help texts.
- [x] `npm test`, build, browser check, push.

## Assumptions
- The 3D topo view was an alternative UI for the same job (pick A/B, route by
  OSRM or A\*); both jobs stay available in the 2D map, so removing it does not
  reduce functionality. The edits are intertwined, so it is one commit;
  `git revert` of that commit brings the builder back.
